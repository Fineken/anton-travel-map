## Маршруты по дорогам

Участки между точками рисуются по реальным дорогам (как если бы ехать на машине; пешие участки — по пешеходным тропам).
Геометрия заранее посчитана через OSRM и лежит в `data/routes.json`. Перелёты — дугой, паромы — пунктиром,
участки без дорожного сообщения — тонкой прямой.

После изменения `data/places.json` пересчитать (уже посчитанные пары берутся из кэша):

```
python tools/build_routes.py
```
